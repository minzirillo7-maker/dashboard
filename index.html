                          Conexión para cargar datos

                          Para vender, cargar stock y crear productos desde el panel. Se configura una sola vez.

                          Sin conectar
                          Cómo conectarlo (5 minutos, una sola vez)
                          1. Tocá Copiar código. Ya trae adentro una clave secreta nueva para tu panel.
                          2. Entrá a script.google.com → Nuevo proyecto con la cuenta dueña de la planilla. Borrá lo que aparece, pegá el código y guardá (Ctrl+S). Ponele de nombre VAPE CREW ADMIN.
                            Tiene que ser un proyecto nuevo, no el del catálogo, así no se pisan.
                          3. Arriba a la derecha: Implementar → Nueva implementación. En el engranaje elegí Aplicación web. Ejecutar como: Yo. Quién tiene acceso: Cualquier usuario (ojo: no la opción "con una cuenta de Google"). Tocá Implementar.
                          4. Google te pide permiso: Autorizar acceso, elegí tu cuenta, Configuración avanzada → Ir a VAPE CREW ADMIN y Permitir. Google avisa que puede ver y editar tus planillas y tu Drive: el script solo usa CLAUDE CATALOGO y una carpeta para las fotos de productos.
                          5. Copiá la URL de la aplicación web (termina en /exec), pegala abajo y tocá Probar conexión.
                          La clave queda guardada solo en este navegador. Para usar el panel en el celu, abrí ahí el link de conexión.
